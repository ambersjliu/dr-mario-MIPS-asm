# Dr. Mario - MIPS assembly
Dr. Mario, written in MIPS assembly.
## Background
This project was written for CSC258 - Computer Organization at the University of Toronto.  
It was developed in the [Saturn](https://github.com/1whatleytay/saturn) interpreter and assembler.
## How to play
Visit the web version of [Saturn](https://1whatleytay.github.io/saturn).  
You will need to copy paste the code from drmario.asm into the editor.  
Click the hamburger menu in the top left, then click "Build" in the dropdown. In the new menu that appears, click "Bitmap" and make sure Display Width and Height are both 32.  
Click the play button in the top right and click the bitmap display to link the keyboard.  
Have fun!
## Controls
- a: move right
- s: move down
- d: move left
- w: rotate
- q: end the game
- p: pause the game
- r: if on a GAME OVER or GAME WIN screen, restarts the game
## Features
1. Background music
2. Sound effects
3. Ability to pause, end the game, and reset
4. Ability to preview where the capsule will drop
